# Portfolio MFY - María Florencia Yofre

Portfolio Data & Operations Analyst.

## Estructura

- `src/data/portfolio.js` -> **ÚNICO ARCHIVO EDITABLE** con todo el contenido
- `src/components/` -> Diseño visual (no modificar si querés conservar el diseño exacto)
- `src/App.jsx` -> Layout principal
- `public/images/` -> Imágenes (banner, perfil, logo)

## Editar contenido

Abrí `src/data/portfolio.js` y modificá:

- personal
- bio
- experiencia
- proyectosData / proyectosWeb
- recomendaciones
- habilidades
- formacion
- contacto

No necesitás tocar ningún otro archivo.

## Desarrollo local

npm install
npm run dev

## Build

npm run build -> genera dist/ listo para Vercel.

Vercel detecta automáticamente Vite.
